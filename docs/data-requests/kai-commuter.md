# Permohonan akses data jadwal dan posisi kereta — KAI Commuter

**Kepada:** PT Kereta Commuter Indonesia (c.q. Divisi Teknologi Informasi / Humas)
**Perihal:** Permohonan akses data jadwal (GTFS) dan posisi Commuter Line secara langsung
**Tanggal:** _(isi saat dikirim)_

Dengan hormat,

Saya <nama>, pengembang **Jalanin** (https://maps.nizmitz.com), aplikasi web peta gratis untuk
warga Jakarta yang menampilkan aturan ganjil-genap beserta jaringan MRT, LRT, KRL, dan
Transjakarta. Aplikasi ini tanpa iklan, tanpa akun, tanpa pelacakan, dan kode sumbernya terbuka
di https://github.com/nizmitz/jalanin.

Data lintas dan stasiun Commuter Line yang kami tampilkan saat ini bersumber dari
OpenStreetMap. Agar informasi yang diterima masyarakat akurat, kami memohon akses ke:

1. **Data jadwal** dalam format GTFS (atau format lain yang tersedia) untuk lintas Commuter
   Line Jabodetabek.
2. **Posisi kereta secara langsung** — sebagaimana ditampilkan pada fitur _Live Tracking_
   aplikasi C-Access — melalui API resmi atau feed GTFS-Realtime `VehiclePositions`.

Komitmen kami sama untuk kedua jenis data:

- Atribusi "Sumber: KAI Commuter" pada setiap tampilan.
- Frekuensi pengambilan sesuai ketentuan Bapak/Ibu, dengan cache di server kami.
- Tidak diperjualbelikan, tidak untuk iklan, tidak disublisensikan.
- Bersedia menandatangani perjanjian penggunaan data dan menghentikan akses bila diminta.

Pengambilan data dilakukan satu arah dari satu server kami (IP statis dapat kami sampaikan);
perangkat pengguna tidak pernah mengakses sistem KAI Commuter secara langsung.

Kami terbuka untuk mengikuti prosedur permohonan data yang berlaku, termasuk pengisian
formulir dan rapat teknis.
